# 03. 总体架构与数据流

```text
浏览器 / Agent / 手机
          |
        HTTPS
          v
 Union（唯一公网入口）
          |
   gateway-v1 + 固定路由
          v
 私有 worker 18101..18105
          |
 PostgreSQL（Sunshine/Host 独占 schema；Sentinel/Photo 专用 database）/ Dufs SQLite
```

Agent 和手机不在服务器进程树内。Photo 内容经过 TLS 到达服务器后以明文文件保存。
