# 03. 总体架构与数据流

```text
浏览器 / Agent / 手机
          |
        HTTPS
          v
 Union（唯一公网入口）
          |
 Manifest 路由 + gateway-v1
          v
 受监管的私有 worker
          |
 各模块专用 PostgreSQL database / Dufs 独立 SQLite + 文件根
```

Builder 决定发行包含哪些 worker 包，Runtime 决定这些包是否运行。Agent 和手机不在服务器进程
树内；Photo 内容经过 TLS 到达服务器后以明文文件保存。
