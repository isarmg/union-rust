# 02. 必要技术基础

Cargo feature 会把代码链接进 binary，因此 v0.5 不用它选择服务器业务模块；Agent 的 OTLP/GPU
等可选采集器仍可使用自己的 feature。Axum 处理 HTTP 边界，Tokio 管理异步任务和私有进程。
Sunshine、Host、Sentinel、Photo 各有专用 PostgreSQL database/role；Union Core 与 Dufs 各有
独立 SQLite，均不是共享数据库。

`gateway-v1` 是 Union→worker 的进程 capability。TLS 是客户端→Union 的传输保护。二者
不能替代用户会话、CSRF、Agent token 或模块域权限。
