# 02. 必要技术基础

Cargo feature 在编译时决定代码是否进入 binary；它不是运行时开关。Axum Router 处理 HTTP
边界，Tokio 管理异步任务和子进程。Sunshine/Host 用 PostgreSQL schema 隔离；Sentinel/Photo
各有专用 PostgreSQL database/role。Union core 与 Dufs 各有私有 SQLite，均不是共享数据库。

`gateway-v1` 是 Union→worker 的进程 capability。TLS 是客户端→Union 的传输保护。二者
不能替代用户会话、CSRF、Agent token 或模块域权限。
