# 04. 共享协议与监控模型

[`host-monitoring`](https://github.com/isarmg/host-monitoring) 仓库中的 `protocol` crate 定义 Agent
与 Host worker 的 DTO、字段约束和兼容测试；同仓维护跨平台 Agent 和 Host worker。Agent 使用
设备凭据访问 Union 的 `/api/modules/host-monitoring/agent/*`；Union 再用 gateway identity 访问
Host worker。Builder 服务器发行纳入 Host worker，Agent companion artifact 则在远端独立安装。

Host worker 独占专用 PostgreSQL database/role（库内 `host_monitoring` schema），保存配对、
credential、最新快照和历史。旧 Union SQLite 只能由离线 importer 读取，不能在线双写或充当
新系统查询源。
