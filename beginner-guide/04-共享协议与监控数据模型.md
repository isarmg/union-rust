# 04. 共享协议与监控模型

`protocol` crate 定义 Agent 与 Host worker 的 DTO、字段约束和兼容测试。Agent 使用设备
凭据访问 Union 的 `/api/modules/host-monitoring/agent/*`；Union 再用 gateway identity 访问
Host worker。

Host worker 独占专用 PostgreSQL database/role（库内 `host_monitoring` schema），保存配对、
credential、最新快照和历史。旧 Union SQLite 只能由离线 importer 读取，不能在线双写或充当
新系统查询源。
