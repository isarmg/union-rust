# 01. 仓库地图

- `server`：唯一公网 gateway、认证、catalog、supervisor；
- `sunshine-worker`、`host-monitoring-worker`：同仓私有 worker；
- `agent`：远端主机 companion；
- `protocol`：Agent/Host 线上 DTO；
- `web`：随 Union Release 的前端。

阅读顺序：先看 `server/src/platform/spec.rs` 的固定图，再看 gateway/supervisor，然后看
worker HTTP 和 migration。不要从旧 SQLite 表反推当前数据模型。
