# 01. 仓库地图

- `server`：唯一公网 Core、认证、动态 catalog、Manifest Gateway 和 Plugin Runtime；
- `web`：随 Union Release 的动态 Shell，不编译业务页面。

本仓库只维护 Core 和 Web Shell。Sunshine 模块位于
[`sunshine-worker`](https://github.com/isarmg/sunshine-worker)；Host worker 与 Agent/Host 线上 DTO
以及跨平台 Agent 均位于 [`host-monitoring`](https://github.com/isarmg/host-monitoring)。其余业务
模块同样由各自仓库维护，再由 Builder 固定 revision 纳入 Union 服务器发行；拆仓不意味着
worker 可以绕过 Union 对公网提供服务。`full` profile 包含 Host worker，但 Agent 是 Host 仓库的
companion artifact，需在远端独立安装，不属于服务器发行或 supervisor 进程树。

阅读顺序：先看 `server/src/platform/package_store.rs`、`runtime.rs` 和 `gateway.rs`，再到目标模块
仓库看根 `manifest.json`、worker HTTP 和 migration；阅读 Agent/Host DTO 时以 Builder/Agent
兼容矩阵对应的 Host revision 为准。不要从旧静态 spec 或 SQLite 表反推当前模型。
