# 01. 仓库地图

- `server`：唯一公网 Core、认证、动态 catalog、Manifest Gateway 和 Plugin Runtime；
- `sunshine-worker`、`host-monitoring-worker`：同仓私有 worker；
- `agent`：远端主机 companion；
- `protocol`：Agent/Host 线上 DTO；
- `web`：随 Union Release 的动态 Shell，不编译业务页面。

阅读顺序：先看 `server/src/platform/package_store.rs`、`runtime.rs` 和 `gateway.rs`，再看各模块
根的 `manifest.json`、worker HTTP 和 migration。不要从旧静态 spec 或 SQLite 表反推当前模型。
