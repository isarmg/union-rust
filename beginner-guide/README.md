# UnionC 零基础教学

> 适用版本：0.3.5
> 教程面向第一次接触 Rust、React 或主机监控项目的读者。

这套文档不是 API 清单，也不是把根目录的 `DOCUMENTATION.md` 换一种说法。它是一条从“能跑起来”到“能沿着真实代码解释系统”的学习路线。每章都会回答四类问题：

1. 这一部分解决什么问题；
2. 为什么项目选择现在的设计；
3. 应该从哪些文件开始读；
4. 如何用命令、测试或浏览器亲手验证。

学完后，你应该能够：

- 区分 Server、Agent、共享协议、Web 管理台和 Sunshine 管理各自的职责；
- 解释一份 CPU 指标从采集到页面显示所经过的完整路径；
- 看懂项目中常见的 Rust、TypeScript、React、HTTP、SQLite 和 SSE 代码；
- 在不破坏安全边界的前提下定位代码、修改功能、补测试；
- 搭建开发环境，并理解生产部署、备份、配对、撤销和故障排查流程。

## 建议学习路线

### 只有 30 分钟

依次阅读第 00、03、04 章。你会得到正确的整体印象，并能说清项目最重要的边界。

### 想改前端

阅读 00 → 01 → 02 中的 TypeScript/React 部分 → 03 → 07 → 10。

### 想改 Server

阅读 00 → 01 → 02 中的 Rust/Axum/SQLite 部分 → 03 → 04 → 05 → 08 → 09 → 10。

### 想改 Agent

阅读 00 → 01 → 02 中的 Rust/异步部分 → 03 → 04 → 06 → 09 → 10。

### 想全面接手项目

按编号顺序阅读，并完成第 12 章的练习。每读完一章，先完成章末自检，再进入下一章。

## 如何使用这套教程

- 完整相对路径以仓库根目录为起点，例如 `server/src/main.rs`；在已明确模块目录的上下文中，会简写为 `model.rs` 一类文件名。
- 命令默认在仓库根目录执行，标明 `cd web` 的除外。
- 教程使用临时数据目录，避免碰到真实部署数据。
- “源码是最终事实”：若教程与代码产生差异，以当前源码、`server/schema/sqlite.sql` 和包清单为准。
- 生产操作只讲原理与安全顺序；完整参数仍应对照根目录的正式运维文档。

## 先记住三个边界

1. UnionC 的 Agent 监控是**只读、单向上报**：Server 不向 Agent 下发命令。
2. Sunshine 管理是独立增强能力，不是 Agent 监控正常工作的前提。
3. 当前版本只支持全新数据布局或同版本备份恢复，不提供旧版本数据库、配置或 Agent 身份的升级桥。
