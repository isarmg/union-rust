# 00. 学习准备

需要 Rust、Cargo、Node/npm、Git 和 PostgreSQL。启用四个 PostgreSQL 模块时分别准备专用
database/role；Core 与 Dufs 各使用自己的 SQLite，Sentinel 可需要 MediaMTX。先运行只读检查：

```bash
cargo metadata --no-deps
cargo test -p sarmg-protocol
cd web && npm ci && npm test
```

完整服务端依赖 Builder 2.0 生成的发行布局和模块配置，优先使用 schema v2 调试 profile，不要
把单个 worker 的开发启动称为部署。
